# Large analysis files

Archive DOI supplied for the manuscript release: [10.5281/zenodo.24467237](https://doi.org/10.5281/zenodo.24467237).

The archive is intended to provide the full and stratified CDS alignments, RDP5.93 projects and breakpoint exports, original GARD inputs, coordinate maps and outputs for seven representatives, and original AlphaFold3 CIF files. The public Zenodo records API returned HTTP 404 for this record during release preparation. The deposited file list remains unverified. Consult the archive record for its deposited files.
