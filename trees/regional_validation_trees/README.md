# Regional maximum-likelihood trees for 54 supported events

Every published event ID has a folder with minor.treefile and major.treefile in Newick format. These are copies of the original primary regional trees. Disjoint spans are represented by the concatenated-region tree.

Coverage is 43 genotype-assigned query events, six unassigned query events, and five reference-only events. The unassigned trees use their own source alignment coordinates. The manifest includes supported accessions, alignment spans, source paths, and SHA-256 checksums.

E090 is excluded in line with the study export filter. Table S2 lists two RDP5 methods for this event, and Table S4 marks it unsupported.
